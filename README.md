## Hướng dẫn Build

### Yêu cầu môi trường
- **JDK**: Java 21 trở lên (khuyến nghị JDK 21 LTS).

## Hướng dẫn Sử dụng

1. **Cài đặt môi trường:**
   - Cài đặt **Minecraft 1.21.11**.
   - Cài đặt **Fabric Loader** cùng **Fabric API**.

2. **Cài đặt Mod:**
   - Copy file `KryptonPlus_Hiech vào thư mục `.minecraft/mods/`.
   - Khởi động Minecraft với profile Fabric.

3. **Thao tác trong Game:**
   - **Mở Menu ClickGUI:** Nhấn phím `RIGHT SHIFT` (Shift phải).
